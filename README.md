# RBO Cinema Season Conversion Tracker

这是一个用于检测和追踪从 **Royal Ballet & Opera (RBO)** 售票网站跳转至各大合作电影院网站（如 Everyman、Picturehouse、Odeon 等）流量与上座率的轻量级转化追踪原型工具。

## 功能特点
- 实时追踪并展示总点击数、售票跳转数及转化率。
- 区分不同影院渠道的数据表现。
- 模拟点击与跳转测试，支持本地缓存和动态图表更新。

## 如何使用
1. 本地直接用浏览器打开 `index.html` 即可预览。
2. 已通过 Vercel 部署上线，可随时访问在线看板。
